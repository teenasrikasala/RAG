# College Policy RAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that answers questions
about college policies using information retrieved from PDF documents.
It combines semantic search with a local Llama 3 model so answers are
grounded in the provided policy documents rather than relying only on
the model's general knowledge.

> **Project status:** Runs locally. The LLM connection currently uses
> Ollama on the same machine, so the chatbot is not a hosted/public web
> app.

## Features

-   Ask questions in natural language about college policies.
-   PDF-based knowledge source for attendance, examinations, hostel
    rules, student conduct, and leave policies.
-   Semantic retrieval using Sentence Transformers embeddings and FAISS
    similarity search.
-   Context-grounded answers generated by Llama 3 through Ollama.
-   Tracks document, page, chunk, and similarity score for retrieved
    content.
-   Fallback response when retrieval does not find sufficiently relevant
    content.
-   Web interface built with HTML, CSS, and JavaScript, served by Flask.

## Tech Stack

  Component                  Technology
  -------------------------- -----------------------------------------------
  Backend                    Python, Flask
  Frontend                   HTML, CSS, JavaScript
  PDF text extraction        PDF library specified in `requirements.txt`
  Text embeddings            Sentence Transformers --- `all-MiniLM-L6-v2`
  Vector similarity search   FAISS (`IndexFlatIP`)
  Similarity measure         Cosine similarity (embeddings are normalized)
  Local language model       Llama 3 via Ollama
  HTTP requests              `requests`

## How It Works

1.  **Extract:** read text from the policy PDFs.
2.  **Chunk:** split extracted text into smaller sections with metadata
    such as page number and chunk ID.
3.  **Embed:** convert each chunk into a 384-dimensional vector using
    `all-MiniLM-L6-v2`.
4.  **Index:** store vectors in a FAISS index for similarity search.
5.  **Retrieve:** convert the user's question into an embedding and
    retrieve the most similar chunks.
6.  **Check relevance:** if the best match is below the configured
    similarity threshold, return a fallback instead of generating an
    unsupported answer.
7.  **Generate:** send the retrieved context and question to Llama 3
    through the local Ollama API.
8.  **Display:** return the answer to the browser through Flask's
    `/chat` endpoint.

## Run Locally

### 1. Clone the repository

``` bash
git clone https://github.com/teenasrikasala/RAG.git
cd RAG
```

### 2. Create and activate a virtual environment

**Windows PowerShell:**

``` powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

If PowerShell blocks activation, run this for the current terminal
session and activate again:

``` powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\venv\Scripts\Activate.ps1
```

**macOS/Linux:**

``` bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Install dependencies

``` bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Install and prepare Llama 3

Install Ollama from [ollama.com](https://ollama.com/download), then run:

``` bash
ollama pull llama3
```

Make sure Ollama is running locally. The application expects its
generation API at:

``` text
http://localhost:11434/api/generate
```

### 5. Start the Flask application

From the project root, run:

``` bash
python app.py
```

Open the local URL printed by Flask in your browser (usually
`http://127.0.0.1:5000`).

## Example Questions

-   What is the attendance requirement?
-   What are the examination rules?
-   What are the hostel rules?
-   What is the leave application process?
-   What conduct is expected from students?

Answers depend on the content of the included policy PDFs. If a policy
does not contain the requested information, the chatbot should avoid
presenting an unsupported answer.

## Notes and Limitations

-   This version is designed to run **locally**. The Ollama URL points
    to the machine running Flask and will not automatically work on a
    cloud host.
-   Answer quality depends on PDF text extraction, chunking, retrieval
    quality, the similarity threshold, and the language model.
-   Similarity scores are relevance signals, not guarantees that an
    answer is correct.
-   Scanned PDFs may need OCR before their text can be retrieved.
-   Keep API keys out of source control if you add an external model
    provider later.
